# 02-assets/ — what you add

| Folder | You add | Needed by |
|---|---|---|
| `logo/` | The real logo (SVG preferred; PNG state its pixel size). A light / transparent version for dark surfaces if dark headers are planned. Type A with the Brand module on: the logo comes from Step 10 | Step 16 |
| `fonts/` | Font files, **or** `font-name.txt` naming one open-source font (e.g. Inter) | Step 16 |
| `icons/` | The client's SVG icons, **or** `icon-library.txt` naming one open-source library (e.g. Lucide) | Step 16 |
| `moodboard/` | 2–4 screenshots of UI styles you like. In Step 17 add `screens/S##-name/` with 3–6 references per key section | Step 17 |
| `images/` | Images generated from Step 20's prompts, named `IMG##-name.png` | Step 21 |

Use only fonts and icons whose licence allows commercial use. Do not copy icons from another product or a paid pack you may not redistribute.
Claude checks all of this in Step 02 and warns about anything missing.
